# TabBar

Barra inferior com as três abas: Hoje, Loja e Perfil.

**O consumidor fornece:** a aba ativa e a navegação.

- Fundo `canvas` com borda superior `line`. Ícones de 20px com rótulo de 12px sempre visível.
- Aba ativa: ícone dentro de uma pílula `primary-soft` e texto `primary-ink`, com `aria-current="page"`.
- Nunca mais de três abas. Configurações fica no Perfil.
- O botão "+" (`am-fab`) flutua acima da barra, no canto direito, a 16px das bordas.
