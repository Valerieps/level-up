# Celebration

Momento de recompensa de peso médio ou alto: Subiu de nível, Automatizado + Prêmio de Domínio e Conquista.

**O consumidor fornece:** tipo, título, frase com o nome do hábito, valor ganho e a ação seguinte.

- Fundo `top` (ameixa), selo em `gold` e valor em `num-lg` `gold`. O dourado é sempre a cor do prêmio.
- Título em `display` (Sora 28px), com ponto de exclamação e no máximo duas palavras.
- Subiu de nível: banner curto no topo que some sozinho e não bloqueia.
- Automatizado e Conquista: interrompem uma vez e fecham com um toque.
- Fila: se uma conclusão gera vários eventos, mostre uma única celebração empilhada, do menor para o maior.
- Movimento: entrada em até 300ms (escala de .96 para 1 e opacidade). Com `prefers-reduced-motion`, só opacidade.
