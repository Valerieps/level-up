# PauseBanner

Faixa discreta logo abaixo do topo quando o app inteiro está em Modo Pausa.

**O consumidor fornece:** data de volta (opcional) e o handler de "Voltar".

- Fundo `neutral-soft`, texto `neutral`. Sem cor de alerta e sem ícone de aviso.
- Não mostre quantos dias de pausa já se passaram nem compare períodos.
- Ao voltar, a faixa some e aparece o toast de retorno.
