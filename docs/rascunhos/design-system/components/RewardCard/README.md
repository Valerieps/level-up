# RewardCard

Cartão de recompensa da vida real na Loja.

**O consumidor fornece:** nome, preço em ouro, saldo atual e o handler de Resgatar.

- Preço em `am-price` (`gold-soft`/`gold-ink`, `num`), sempre com o ícone de moeda.
- Saldo insuficiente: botão desabilitado com o quanto falta ("Faltam 172 ouro"), nunca uma mensagem de erro.
- Use "Resgatar", nunca "Comprar".
