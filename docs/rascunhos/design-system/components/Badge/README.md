# Badge

Pílula curta para selos e estados. Sempre tem texto, nunca só cor.

**O consumidor fornece:** o texto e a variante.

| Variante | Classe | Uso |
| --- | --- | --- |
| Automatizado | `am-badge-auto` | Selo de domínio (`primary-soft`/`primary-ink`) |
| Faz tempo | `am-badge-faz` | Livre parado 10+ dias (`faz-soft`/`faz`) |
| Opcional | `am-badge-opt` | Hábito pausado que ainda pode ser marcado |
| Prêmio | `am-badge-gold` | Estrelas, Prêmio de Domínio, conquistas |
| Sucesso | `am-badge-success` | Feito, sincronizado |
| Atenção | `am-badge-warning` | Parcial, sincronização pendente |
| Neutro | `am-badge` | Arquivado, pausado |
| Erro | `am-badge-danger` | Só falha de ação ou validação. Nunca para hábito não feito |

- Estilo `label` (12px, 600). Raio `radius-sm`.
- Use as palavras do vocabulário controlado ("Automatizado", nunca "Dominado").
